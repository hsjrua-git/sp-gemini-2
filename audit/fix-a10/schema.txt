 avg_cost   | bigint  |           |          |         | plain    | 
View definition:
 SELECT p.id AS product_id,
    p.name,
    p.is_active,
    COALESCE(sum(m.qty), 0::numeric) AS qty,
    p.avg_cost
   FROM cafe_products p
     LEFT JOIN cafe_stock_movements m ON m.product_id = p.id
  GROUP BY p.id, p.name, p.is_active, p.avg_cost;
